Да, залез и посмотрел именно строительство кораблей / обороны в сохранённых страницах Nemexia_auto_v2. Пока ничего не генерирую.

Как это реально сделано в Nemexia

Нашёл сохранённый экран ships.php?show=CommanderShips. Причём внутри это один общий строительный раздел «Корабли», а переключение между типами идёт без перехода на другой глобальный экран:


  • Корабли

  • Оборона

  • Боевые корабли


При нажатии обычных кораблей Nemexia вызывает showTab('TabShips') + refreshShipyard('Ships'), а оборона — showTab('TabDefence') + refreshShipyard('Defence'). То есть твоя идея с переключателем Корабли ↔ Оборона полностью соответствует оригинальной логике игры.

Сам экран кораблей

Это именно каталог производства, а не список летающих флотов. У каждого корабля есть:


  • картинка;

  • название;

  • сколько уже доступно;

  • стоимость в металле / минералах / газе;

  • расход населения;

  • требования;

  • характеристики вроде скорости и топлива;

  • состояние доступен / заблокирован;

  • количество для производства.


Сверху/рядом есть общее время производства, а дальше идёт команда «Строительство корабля».


Причём в сохранённой расе реально есть, например:


  • Солнечный спутник;

  • Шпионский зонд;

  • Транспортировщик;

  • Мегатранспортировщик;

  • Колонизатор;

  • Переработчик;

  • Скаут;

  • Крейсер;

  • Защитник;

  • Боевой корабль.


У заблокированных прямо показывается причина вроде «нужен 4 уровень Верфи» или определённая технология.

Оборона — практически тот же UX

Переключаешь вкладку — центральный каталог заменяется на оборонительные единицы. Там те же принципы:


  • изображение;

  • текущее количество;

  • стоимость;

  • требования;

  • производство;

  • блокировка, если не выполнены технологии/уровень Верфи.


Например, в сохранённой странице есть:


  • Баллистическая установка;

  • Лазерная установка;

  • Ионная установка;

  • Плазменная установка;

  • Лазер-Ионная батарея;

  • Плазма-Лазерная батарея;

  • Ион-Плазменная батарея;

  • Башенный щит;

  • Планетарный щит.


И ещё важный момент: Nemexia отдельно считает pop_used для кораблей и defence_pop_used для обороны, но оба сравниваются с общей вместимостью pop. То есть наша верхняя сущность «Население 4/70» вполне может остаться единственным общим лимитом без отдельного «Ангара».

Я бы действительно поменял нашу структуру

Твоя новая идея, по-моему, лучше предыдущей:

Флоты

Сделать не «куда что летит», а военно-производственный раздел:


ФЛОТЫ

[ КОРАБЛИ ] [ ОБОРОНА ]

 ┌──────────┐ ┌──────────┐ ┌──────────┐
 │ корабль  │ │ корабль  │ │ корабль  │
 │ картинка │ │ картинка │ │ картинка │
 │ Крейсер  │ │ Скаут    │ │ ...      │
 │ есть: 12 │ │ есть: 4  │ │          │
 │ стоимость│ │ стоимость│ │          │
 │ -  0  +  │ │ -  0  +  │ │          │
 └──────────┘ └──────────┘ └──────────┘

              ОЧЕРЕДЬ ПРОИЗВОДСТВА

Справа можно сделать красивую очередь строительства кораблей/обороны, в том же стиле, как уже сделали очередь зданий на планете.


Слева остаётся наш неизменный shell:


  • мини-планета;

  • три зоны;

  • текущая планета ▼.


И я бы не тащил «Боевые корабли» третьей вкладкой сейчас, пока это не нужно нашей механике. Основные две:


Корабли | Оборона

А «Операции» тогда получает то, что мы сделали раньше для флотов

Это даже логичнее:

Операции

Экран 1:


  • текущие полёты;

  • От / До / Прибытие / Возвращение / Вид / Опции;

  • выбор кораблей;

  • выбор миссии;

  • Продолжить.


Экран 2:


  • От → До;

  • координаты;

  • время прилёта/возврата;

  • скорость;

  • расстояние;

  • расход газа;

  • груз;

  • загрузка ресурсов;

  • Отправить флот.


То есть получается очень понятное разделение:

Флоты = чем я располагаю и что строю.
Операции = куда я это отправляю и что оно делает.

Я бы именно эту структуру теперь зафиксировал как основную. Она и ближе к Nemexia, и для нашего интерфейса заметно понятнее.
